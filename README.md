# 🍅 Tomato Leaf Disease Detection — CNN (Python & TensorFlow)

A deep learning project that detects diseases in tomato plants from images of their leaves, using a **Convolutional Neural Network (CNN)** built with **Python and TensorFlow**.

Early detection of plant diseases helps farmers act before an infection spreads and damages the whole crop. This project trains a CNN model to look at a tomato leaf image and classify the plant's health condition.

## How It Works
1. **Image dataset** — the model is trained on labelled images of tomato leaves (healthy and diseased).
2. **Preprocessing** — images are resized, normalized and prepared for training, with the data split into training and validation sets.
3. **CNN model** — a convolutional neural network built with TensorFlow/Keras learns the visual patterns (spots, discoloration, texture changes) that distinguish one condition from another.
4. **Training & evaluation** — the model is trained over multiple epochs and evaluated on unseen validation images.
5. **Prediction** — a new leaf image given to the trained model returns the predicted condition.
